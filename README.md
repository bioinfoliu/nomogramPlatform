# MCN Malignancy Risk Calculator

This repository contains the web-based nomogram platform for estimating the probability of advanced neoplasia in patients with mucinous cystic neoplasm (MCN) of the pancreas.

The calculator uses a logistic regression-based nomogram developed from an international multicenter MCN cohort. Users can enter patient-level clinical variables and obtain an individualized predicted probability of MCN advanced neoplasia.
